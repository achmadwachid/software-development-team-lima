## Deskripsi Peran
Project Manager mengawasi alur pekerjaan setiap anggota tim dan memastikan koordinasi berjalan efektif agar proyek dapat diselesaikan dengan lancar.

## Kontribusi yang sudah dilakukan
1. Membuat repository kelompok di GitHub
2. Membuat file README.md awal dengan:
   - Nama kelompok Lima
   - Nama anggota
   - Mata kuliah
   - Deskripsi repository
3. Menambahkan anggota lain sebagai collaborator:
   - Frontend Developer
   - Backend Developer
4. Membuat struktur awal repository agar siap digunakan anggota lain
